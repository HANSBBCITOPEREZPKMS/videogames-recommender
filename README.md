# 🎮 Recomendador de Videojuegos por Características

Aplicación web en **PHP + HTML + CSS** que recomienda videojuegos según su característica.
Usa un **API REST** con métodos GET, POST, PUT y DELETE, y almacena los datos en un archivo CSV.

## 🚀 Características
- Buscar juegos por tipo (aventura, acción, deportes, etc.)
- Agregar nuevos juegos
- Actualizar características
- Eliminar juegos

## 🧠 Tecnologías
- PHP
- HTML / CSS / JavaScript
- CSV (sin base de datos)
